# ☕ SONSUZ KAHVE MOLASI YÖNETİCİSİ ☕

## Dünyanın En Önemli Yazılımı (Gerçekten)

Bu proje, insanlığın karşılaştığı en büyük sorunu çözmek için geliştirilmiştir: **Kahve molalarının sonsuza kadar sürmesini sağlamak.**

### Neden Bu Kadar Kritik?

- Çalışanlar sabah 09:00'da işe geliyor.
- 09:05'te kahve molası başlıyor.
- 18:00'e kadar devam ediyor.
- Bu sistem sayesinde verimlilik %0'a düşüyor, moral %1000 artıyor.
- Bilimsel kanıt: "Bir yerlerde birileri bir şeyler demiş olabilir."

### Özellikler

- **Sonsuz döngü koruması**: Program asla bitmez (istemezsen).
- **Akıllı mola hesaplama**: Rastgele sayılarla "optimal" mola süresi üretir.
- **Duygusal destek**: Her 3 dakikada bir seni tebrik eder.
- **Kahve seviyesi monitörü**: Hayali kahve seviyenizi takip eder.
- **Acil durum modu**: Kahve biterse panik atar (ama yine de mola verir).

### Kurulum

```bash
python sonsuz_kahve.py
```

Python 3.x yeterli. Başka hiçbir şeye ihtiyacın yok. İnternet bile gerekmez. Sadece sen ve sonsuz kahven.

### Kullanım

Programı çalıştır. Sonsuza kadar mola yap. Çıkmak için Ctrl+C (ama niye çıkasın ki?).
